# Streams — Home Task

Practice exercises using Java 8+ Stream API.
Constraints: no if-else, switch-case, or char primitives — solved using stream operations instead.

## Tasks
1. Stream creation, Stream.generate(), filtering into a List
2. Array collection, filtering/sorting strings
3. Predicate matching (allMatch/anyMatch/noneMatch), count, findFirst
4. flatMap, distinct, (optional) Collectors.toMap
5. Extracting values from a Map<String, List<String>>

## How to run
Each task has a `main()` for manual output, and a corresponding `*Test` class runnable via IntelliJ.
